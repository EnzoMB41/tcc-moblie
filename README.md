# Aplicativo Discoffe 

## Sobre o aplicativo

A Discoffe é uma experiência que mistura o melhor de uma cafeteria com a energia de uma discoteca. Este aplicativo, desenvolvido em Flutter, apresenta a empresa, mostra o cardápio e apresenta o ReHarmonia, o jogo criado para divulgar a cafeteria, com sua história, personagens e mecânicas.

O app funciona como uma vitrine: o cardápio é apenas de exibição, sem vendas, login ou contas de usuário. Ao jogar o ReHarmonia, o usuário acumula pontos que podem ser usados em compras na Discoffe.


## Tecnologias Utilizadas

- Flutter e Dart: desenvolvimento do aplicativo
- JSON: armazenamento do conteúdo (textos, cardápio, personagens e mecânicas)
- video_player: reprodução do trailer do jogo
- url_launcher: abertura dos links de contato
- Canva: criação do protótipo das telas
- Git e GitHub: controle de versão e documentação
